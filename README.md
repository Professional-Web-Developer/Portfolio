# Kavin Pasupathy - Professional Portfolio

A modern, high-end, and responsive portfolio website built with **Next.js 14**, **Framer Motion**, and **Lucide React**.

## 🚀 Built With

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: Vanilla CSS with modern Glassmorphism and 3D Effects
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Components**: Material UI (LinearProgress)

## ✨ Key Features

- **Advanced Tech Stack**: Highlighting proficiency in MERN Stack, Next.js, Docker, SQL, and more.
- **Interactive UI**:
    - **3D Tilt Effect**: Projects react to mouse movements with dynamic perspective.
    - **Organic Morphing**: Fluid background animations for a modern "tech" atmosphere.
    - **Text Reveal**: Smooth typography animations for high-end look and feel.
- **Responsive Design**: Optimized for all screen sizes from mobile to wide monitors.
- **Professional Timeline**: Categorized view of Work Experience and Education history.
- **Achievements Section**: Spotlighting LeetCode rankings and academic milestones.

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `src/app/`: Core layout and global styles.
- `src/components/`: Reusable React components (Hero, Experience, Projects, etc.).
- `public/assets/`: Static assets like images and the downloadable resume.
